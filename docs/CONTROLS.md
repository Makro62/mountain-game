# Kontrol — Mountain Game

Sudut pandang **third-person**: kamera mengikuti dari belakang karakter pendaki.
Mouse (klik kanvas dulu) memutar kamera; A/D atau ←/→ menggeser karakter ke kiri-kanan relatif pandangan.
Kamera otomatis membuntuti arah jalan maju bila mouse diam (mati saat mundur/strafe).

## Gerak & Kamera

| Tombol | Aksi |
| :--- | :--- |
| **W A S D / panah** | Maju / kiri / mundur / kanan (relatif pandangan) |
| **A / D atau ← / →** | Geser karakter ke kiri-kanan |
| **Mouse** | Putar kamera mengelilingi karakter (klik kanvas untuk kunci pointer) |
| **Shift** | Sprint (lebih cepat, kuras stamina ~2x) |
| **Spasi** | Lompat kecil |

## Item & Interaksi

| Tombol | Aksi |
| :--- | :--- |
| **1** | Pakai 🍙 Bekal (+30 stamina) |
| **2** | Pakai 🧥 Jaket (+30 suhu) |
| **3** | Pakai 🩹 P3K (+40 stamina & suhu) |
| **4** | Pakai 🫁 Oksigen (+50 oksigen) |
| **E** | Dirikan tenda di pos (save) — harus di dalam radius pos; petik 🌸 edelweiss terdekat |
| **Esc** | Pause / lepas pointer-lock (lepas kunci otomatis pause) |

Aturan HUD ikut `cs-game`: satu tombol **MENU [ESC]** di HUD. Semua pengaturan/restart/keluar ada di layar pause, bukan tombol dobel di pojok.

## Tips

- Ikuti penanda merah + minimap di kanan atas (jalur berkelok, bukan garis lurus).
- Sprint hanya di jalur landai; matikan saat nanjak curam agar stamina awet.
- Malam + hujan = suhu turun cepat. Segera pakai jaket / menepi ke pos dan tekan `E`.
- Di atas 35 m oksigen menipis. Hemat tabung oksigen untuk Pos 3 → Puncak.
