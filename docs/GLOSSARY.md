# Glosarium — Mountain Game

| Istilah | Arti (1-2 kalimat) |
| :--- | :--- |
| Basecamp | Titik start pendakian di kaki gunung (z=150). Save awal. |
| Pos | Checkpoint 1-3 di jalur. Masuk radius = unlock + auto-save. |
| Puncak | Tujuan akhir (z=-150). Masuk radius = menang. |
| Stamina | Energi 0-100. Habis saat lari/nanjak. Nol = evakuasi (kalah). |
| Suhu | Hangat tubuh 0-100. Turun saat malam/hujan/badai/ketinggian. Nol = hipotermia (kalah). |
| Oksigen | Kadar oksigen 0-100. Menipis di atas 35 m. Nol = stamina terkuras 5x. |
| Bekal 🍙 | Item +30 stamina. |
| Jaket 🧥 | Item +30 suhu. |
| P3K 🩹 | Item +40 stamina & suhu. |
| Oksigen 🫁 | Item +50 oksigen. |
| Tenda | Dibangun otomatis di pos + via `E`. Titik save. |
| Edelweiss 🌸 | Bunga langka zona salju (12 titik). Petik via `E`: +5 stamina, dihitung di peringkat finish. |
| Zona salju | Di atas 40 mdpl: hujan salju, suhu −2x, gerak ×0,85. |
| Batu jatuh 🪨 | Bahaya saat badai di 25–58 mdpl: −12 stamina & −8 suhu jika kena. |
| Pintasan | Jalur oranye putus-putus: lebih pendek, jauh lebih curam. |
| Minimap | Peta top-down di HUD: jalur, pintasan, sungai, pos, posisi pemain. |
| Peringkat | S/A/B di layar menang dari waktu tempuh + jumlah edelweiss. |
| Kabut | Cuaca yang menebalkan fog dan mengurangi oksigen. |
| Badai | Cuaca terberat: suhu turun tercepat + angin kencang. |
| Pointer-lock | Mode klik kanvas agar mouse memutar kamera orbit third-person. |
| Heightmap | Fungsi `getHeight(x,z)` — satu sumber kebenaran tinggi terrain untuk visual + collision. |
